# 완료 조건과 증거 연결

아래는 `plan.md`의 원문 완료 조건을 실행 가능한 검증 항목으로 펼친 목록이다. 성공한 명령·환경·커밋과 산출물이 있어야 통과로 기록한다.

| ID | 검증 | 필요한 증거 | 상태 |
| --- | --- | --- | --- |
| A01 | 근거 → 공고 분석 → 문서 → 프로젝트 → 면접 추적 | 실제 DB/API에서 ID 연쇄 및 소유권 | 미검증 |
| A02 | 서로 다른 공고 두 개의 문서·버전·지원 격리 | 공고 A/B 교차 요청 거부 및 각각 보존 | 미검증 |
| A03 | 근거 없는 수치·기술·경력 확정 차단 | 조작된 문장 확정 요청이 거부됨 | 미검증 |
| A04 | PDF 한글·페이지·링크·ATS | 생성 PDF, 텍스트 추출, 페이지 이미지 | 미검증 |
| A05 | DOCX 한글·페이지·링크 | 생성 DOCX XML 및 렌더 결과 | 미검증 |
| A06 | Google/GitHub OAuth 복귀와 토큰 만료 | PKCE/state/회전 로컬 검사 + 실계정 왕복 | 실계정 준비 전 |
| A07 | 오프라인 편집과 충돌 | 재시작 후 보존·서버 revision 충돌 복구 | 미검증 |
| A08 | Stripe 웹훅 중복 | 유효 HMAC 반복 전송에도 원장 1회 반영 | 미검증 |
| A09 | 세 CLI 미설치·거부·실패·검증 성공 | 공급자별 로컬 실행 및 상태 전이 증거 | 미검증 |
| A10 | 미승인 지원 제출 금지 | 승인 없음/거부/다른 지원 승인 모두 거부 | 미검증 |
| A11 | 민감 내용 로그·분석 이벤트 미포함 | 토큰·키·메일·이력서 sentinel 로그 검사 | 미검증 |
| A12 | 키보드·VoiceOver·축소 창·다크 모드 | 실제 앱 상호작용 및 화면 비교 | 미검증 |
| A13 | 20명 중 16명 실제 흐름 완료 | 익명화된 참가자별 결과 기록 | 사용자 후속 준비 |
| A14 | 서명·공증 Universal DMG와 업데이트 | Apple 검증·설치·업데이트·위조 서명 거부 | 사용자 후속 준비 |
| A15 | 작업공간 재현 | 새 clone --recurse-submodules 및 각 테스트 | 미검증 |

UI의 챔피언/도전자 비교는 고정된 v6 이미지를 참조하며, 코드/문서 비교는 계획을 참조한다. 별도 새 컨텍스트 critic이 불변 A/B 산출물과 해당 버전 테스트를 직접 확인한다. 비교가 차단되었거나 수정 가능한 차이가 남으면 통과가 아니다.
