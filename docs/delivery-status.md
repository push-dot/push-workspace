# 구현·출시 검증 현황

계획 원문은 `plan.md`이며 아래 상태는 실제 증거에 따라 갱신한다. 코드 존재, 로컬 테스트, 외부 서비스 검증, 베타 완료는 서로 다른 상태다.

| 단계 | 상태 | 완료 증거 |
| --- | --- | --- |
| API 계약 | 문서 작성 완료 | 원본 workspace `docs/api.md`에 v1 계약 작성; 구현 일치 검증은 진행 중 |
| 저장소 분리 | 원격 생성 완료 | 비공개 `push-dot/push-fe`, `push-dot/push-be`; workspace gitlink 통합 진행 중 |
| 1. 독립 도메인 신규 구현 | 진행 중 | 기존 코드 참조 없이 API 계약에 따라 개발 |
| 2. 데스크톱 셸 | 진행 중 | 오른쪽 패널 없는 최종 v6 프로토타입 적용 |
| 3. 근거·문서·출력 | 대기 | 한국어 PDF/DOCX 실제 추출 검증 필요 |
| 4. 지원 생명주기 | 대기 | 서로 다른 공고 간 격리 검증 필요 |
| 5. CLI 실행·검증 | 대기 | 3개 CLI의 승인/거부/실패/성공 검증 필요 |
| 6. 외부 연동 | 대기 | 실제 OAuth·AI·Stripe·Google 계정 검증 필요 |
| 7. 서명·공증·베타 | 외부 입력 필요 | 인증서, 업데이트 키/호스트, 배포 환경, 베타 참가자 필요 |

## 실제 서비스 검증에 필요한 입력

민감한 값은 채팅이나 저장소에 쓰지 않고 배포 환경 또는 GitHub Actions secrets에 설정한다.

- Google/GitHub OAuth 앱 등록, 리디렉션 URI와 비밀 값.
- 관리형 OpenAI 계정과 공급자별 테스트 BYOK.
- Stripe 테스트/운영 제품·가격·웹훅 설정.
- Google Gmail 제한 범위 검증 및 Calendar 테스트 계정.
- Hostinger VPS 접속과 API/업데이트 도메인 DNS.
- Apple Developer ID 인증서·공증 권한 및 Tauri 업데이트 서명 키.
- Wanted/Jumpit/JobKorea 자동화 허가 확인.
- 20명 베타 참가자와 실제 공고 등록→문서 생성→지원 추적 성공 기록(최소 16명).

이 항목은 로컬 테스트나 모의 응답으로 완료 처리하지 않는다. 허가 확인 전 채용 사이트 자동 제출은 비활성화한다.
